노트북용 문제제작기 (Windows 64비트)

1. notebook 폴더 전체를 USB나 드라이브로 노트북에 복사하세요.
2. 압축 파일로 옮겼다면 먼저 압축을 모두 풀어 주세요.
3. START.cmd를 더블클릭하면 브라우저에서 문제제작기가 열립니다.
   Node.js 설치나 npm install은 필요하지 않습니다.
4. 실행 창은 작업 중 열어 두세요. 종료할 때 Ctrl+C를 누르세요.

주소: http://127.0.0.1:5174/problem-maker/
Chrome 또는 Edge에서 사용하는 것을 권장합니다.

집으로 문제 옮기기
- 문제를 완성한 뒤 내보내기 탭 → ZIP으로 내보내기.
- 다운로드한 ZIP을 notebook/옮길문제 안의 해당 카테고리 폴더에 모아 주세요.
- 기업로고, 스포츠, 국가, 애니메이션, 밈, 포켓몬 폴더를 준비했습니다.
- 필요한 카테고리 폴더만 USB로 복사하면 됩니다. ZIP이 자동으로 분류되지는 않습니다.
- ZIP을 USB나 드라이브에 저장해 집 PC로 가져갑니다.
- 집 PC 문제제작기 → 기존 문제 열기 → ZIP 선택 → 원본 ID 유지.
- 게임 프로젝트에 바로 추가 → 집 PC의 C:\colorguesser 선택.

이 폴더에는 기존 게임 문제 사진을 넣지 않았습니다.
카테고리는 유지하고 문제 목록은 빈 상태로 시작합니다.
노트북에서 폴더에 직접 저장하려면 notebook 폴더를 선택할 수 있습니다.
브라우저 임시저장은 다른 PC로 자동 이동하지 않습니다. ZIP 저장을 꼭 하세요.
집 PC에 같은 ID가 있으면 덮어쓰기 전에 내용을 확인하세요.
데일리 퀴즈는 다른 카테고리의 문제를 섞어 사용하므로 별도 문제 폴더가 없습니다.
집 PC의 카테고리 JSON 파일을 통째로 덮어쓰지 말고 ZIP 가져오기를 사용하세요.
